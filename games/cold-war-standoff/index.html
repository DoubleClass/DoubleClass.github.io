概览 / OVERVIEW

一场发生在牌桌上的世界角力

你与另一位玩家分别代表华盛顿与莫斯科。每张牌既是一段历史事件，也是一份有限资源；真正困难的不是有没有好牌，而是何时承受代价、把力量投向哪里。

01

争夺影响力

在不同地区部署有限点数，建立控制并改变全球态势。

02

权衡事件

打出卡牌时，在执行历史事件与使用行动点之间选择。

03

守住核门槛

冒险能换来局部优势，但失控的危机也可能终结对局。

开局流程 / START

四步进入战情室

  1. 01

    填写代号

    双方各自输入一个本局使用的名字。

  2. 02

    创建房间

    房主建立战情室，获得一组房间码。

  3. 03

    发送邀请

    把房间码或带参数的邀请链接发给朋友。

  4. 04

    等待入席

    另一位玩家加入后，棋盘会自动打开。

玩法档案 / FIELD NOTES

每次行动都在改变下一轮

事件牌

牌面事件会改变影响力、军事行动或紧张局势；阵营归属让出牌时机格外重要。

地区控制

国家稳定度和双方影响力共同决定控制权，区域优势则会推动胜利点变化。

DEFCON

政变可能让局势进一步紧张。越接近核危机，能够冒险的区域就越少。

行动轮

每轮可用行动有限；现在投入的点数，也意味着放弃另一处机会。
